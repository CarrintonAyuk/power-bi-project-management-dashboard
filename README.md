# 📊 Power BI Project Management Dashboard

An interactive **Power BI Project Management Dashboard** designed to provide a clear overview of project portfolios and detailed project-level performance.

The dashboard demonstrates how project data can be transformed into meaningful, interactive visualisations to support **project monitoring, performance analysis, and data-driven decision-making**.

---

## 🎯 Project Objective

The objective of this project is to develop an interactive reporting solution that enables users to:

* Monitor multiple projects from one dashboard
* View project performance at portfolio level
* Explore individual projects in greater detail
* Track important project metrics and KPIs
* Identify trends and areas requiring attention
* Support informed project management decisions

---

## 📑 Dashboard Pages

The Power BI report consists of **two interactive pages**:

### 1. 📁 Project Portfolio

The **Project Portfolio** page provides a high-level overview of the projects.

It allows users to quickly assess the overall portfolio and interact with the dashboard to explore project information and performance indicators.

### 2. 🔍 Project Details

The **Project Details** page provides a more detailed view of individual projects.

Users can select and analyse specific projects, allowing them to move from a portfolio-level overview to more focused project-level insights.

## 🚀 How to View the Dashboard

1. Download the `.pbix` file from this repository.
2. Open the file using **Microsoft Power BI Desktop**.
3. Navigate between the **Project Portfolio** and **Project Details** pages.
4. Use the available filters, slicers, and interactive visualisations to explore the dashboard.
